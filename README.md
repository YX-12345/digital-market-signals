# Digital Market Signals

AI-assisted Technology Intelligence & Knowledge Hub

[Visit the portfolio site](https://yx-12345.github.io/digital-market-signals/)

Digital Market Signals is an independent portfolio project in development. Its initial research focus is **AI Infrastructure & Cloud Markets in Emerging Economies**, including AI compute capacity, cloud service availability, and policies that shape access.

The homepage presents the project scope and proposed research methodology. The Market Intelligence Tracker and Knowledge Library are in development. The site currently contains no research findings, tracker entries, or published source library.

## Updating the homepage

GitHub Pages publishes the repository root on the `main` branch. The homepage copy and styles live in `index.html`. Edit that file and commit to `main` to publish updates at the same URL. Keep existing section IDs stable so links into the page continue to work.
